# Lot 3 · Découverte de lieux (Overpass, Geoapify, Wikipédia)

- Date : 2026-11-16
- Type : fonctionnalité
- Issue : #5 (épique #1)

## Demande

Proposer les lieux de la zone visible de la carte par catégorie (restaurants, cafés, musées, attractions, monuments, points de vue, parcs, plages, shopping), avec des API gratuites. Un résultat s'ajoute en un clic au jour sélectionné ou aux idées.

## Décisions et pourquoi

- **Cases de cache au zoom 13** (le plan prévoyait 14) : au zoom 12, la zone visible fait une vingtaine de cases du zoom 13, sous le plafond de 40. Au zoom 14, il en faudrait plus de 60, et on demanderait de zoomer dès le zoom 12.
- **Une seule requête fournisseur** par recherche : les catégories manquantes, sur la zone qui couvre les cases manquantes. Les résultats sont répartis par case ; une case sans lieu est mise en cache vide.
- **Réponse Overpass tronquée** (`remark` contenant « error », renvoyée avec un statut 200) : traitée comme un échec, pour ne pas mettre en cache 7 jours une zone incomplète.
- **Overpass factice pour les e2e** (le plan prévoyait une interception Playwright) : comme Photon, Overpass est appelé par le Worker, donc une interception dans le navigateur ne le verrait pas.
- **Site, téléphone et cuisine dans les notes** de l'étape plutôt que dans de nouvelles colonnes : aucun écran ne les exploite encore. Les horaires vont dans `opening_hours`, désormais modifiable dans l'éditeur.
- **Wikidata d'abord** pour le résumé : il permet de trouver l'article français même si le tag `wikipedia` est en anglais.
- **Sécurité** :
  - la langue d'un tag `wikipedia` devient un sous-domaine de `wikipedia.org` : elle est validée strictement ;
  - les liens issus d'OSM et de Wikipédia sont restreints au http(s).
- **Viewer** : il peut explorer, mais ne voit aucun bouton d'ajout ; l'API refuse de toute façon l'écriture (403).

## Bugs et pièges rencontrés

- **Sélecteurs ambigus** :
  - le libellé de catégorie (« Musées ») apparaît aussi dans les cartes de lieux : tests et e2e passent par le groupe « Catégories » ;
  - le nom accessible d'une carte d'étape commence par son numéro : pas d'ancre `^` dans les sélecteurs.
- **Écriture de fichiers par Python sous Windows** : le mode texte convertit en CRLF. Écrire avec `newline=''`.
- **Overpass public saturé** le 16/11/2026 :
  - `overpass-api.de` répondait « at capacity » ;
  - `overpass.private.coffee` mettait plus de 25 s ;
  - `maps.mail.ru` répondait une fois en 15 s, puis en 504.

## Revue

- **Important, corrigé** : une réponse Overpass tronquée aurait été mise en cache 7 jours (test ajouté).
- **Mineur, corrigé** :
  - tag `wikidata` à valeurs multiples (`Q1;Q2`) ;
  - liens Wikipédia (`url`, vignette) filtrés en http(s) côté Worker.
- **Laissé ouvert, noté dans la spécification** :
  - sans clé Geoapify, pas de secours quand Overpass est saturé ;
  - Geoapify plafonne à 500 lieux par appel ;
  - le cache n'est jamais purgé.
