# Lot 1 · Voyages, jours, partage et écran carte

- Date : 2026-11-15
- Type : fonctionnalité
- Issue : #3 (épique #1)

## Demande

Gérer les voyages et leurs jours, avec un partage par voyage en lecture seule ou en modification. Poser l'écran principal :

- la liste des voyages ;
- la page voyage, avec les onglets de jours, le panneau gauche redimensionnable et la carte MapLibre à droite.

## Décisions et pourquoi

- **Fabrique `createApp({ auth })`** pour les tests d'API : une identité injectée par en-tête de test, sans JWT. Les routes tournent sur la vraie D1 du runtime workerd.
- **En-tête `x-dev-user-email`** pour les e2e à plusieurs utilisateurs. Il n'est actif que si `ACCESS_AUD` est absent, la même condition que `DEV_USER_EMAIL`, et il est testé comme ignoré en production.
- **Non-membre : 404 ; membre sans le droit : 403.** On ne révèle pas l'existence d'un voyage.
- **Verrou optimiste atomique** : l'incrément de version et les modifications partent dans un seul `db.batch`. Chaque requête est conditionnée à la nouvelle version, donc en cas de conflit rien n'est modifié.
- **Jour « non vide » = notes renseignées**, tant que les étapes n'existent pas. Le lot 2 étendra la règle.
- **Couleur de voyage non stockée** (prévue dans le plan) : la teinte est dérivée de l'identifiant.
- **Fenêtres en `div role="dialog"`** plutôt que `<dialog>` natif : jsdom n'implémente pas `showModal`, et le rendu reste identique.
- **`maplibre-gl` 6.16.0** (et non la 6.18.0 publiée 4 jours plus tôt) : une version plus mûre.

## Bugs et pièges rencontrés

- **Worker MapLibre introuvable en build** : MapLibre 6 calcule l'URL de `maplibre-gl-worker.mjs` à partir de `import.meta.url`. Après bundling, le fichier n'existe pas et le Worker Cloudflare renvoie le fallback HTML (« Worker failed to load »). Correctif : `import('…/maplibre-gl-worker.mjs?url')` puis `setWorkerUrl`, avec `mjs` ajouté au précache. L'e2e dédié a d'abord échoué.
- **Double décodage des e-mails** : `c.req.param()` de Hono décode déjà. Un `decodeURIComponent` en plus faisait planter la route pour un e-mail contenant `%`.
- **Cohérence des heures** : la règle « fin après début » n'était vérifiée que si les deux champs arrivaient ensemble. Elle est maintenant contrôlée avec les valeurs existantes, pour le voyage comme pour un jour.
- **E2E `getByLabel('Du')`** : la correspondance partielle insensible à la casse trouvait aussi « Nom du voyage ». Utiliser `{ exact: true }`.
- **E2E service worker** : le précache est passé à 1,6 Mo avec MapLibre, et l'activation dépassait les 5 s par défaut de `expect.poll` en parallèle. L'attente est montée à 20 s.
- **Tests d'API** : l'isolation du stockage entre tests n'est pas garantie. Les assertions filtrent sur leurs propres données.
- **Mise à jour PWA** : constatée en vrai dans le navigateur. L'ancienne version en cache affichait « Nouvelle version disponible », et « Recharger » a bien chargé la nouvelle.
