- Date : 2026-11-15

## Demande

Ajouter les étapes d'un jour en timeline chronologique (point géographique, nom, type, durée, heure fixe, notes, réservation), les dossiers (étape parente), la liste d'idées, les séjours sur plusieurs nuits injectés en début et fin de journée, la recherche de lieux, et les marqueurs numérotés sur la carte, synchronisés avec la timeline.

## Décisions et pourquoi

- **Glisser-déposer HTML5 natif** plutôt que `svelte-dnd-action` : zones imbriquées simples et e2e Playwright fiables (`dragTo`). Alternatives clavier : monter/descendre, changer de jour dans l'éditeur.
- **Clés fractionnaires** (`fractional-indexing`) : un déplacement ne réécrit qu'une ligne.
- **Séjours non stockés par jour** : occurrences calculées par `dayTimeline`, avec une clé stable réutilisable par les trajets (lot 4).
- **Fuseau calculé côté Worker** (`@photostructure/tz-lookup` 11.7.0, version de plus de deux semaines) : la table ne doit pas alourdir le front.
- **Photon via le Worker**, URL configurable (`PHOTON_URL`), ce qui permet un Photon factice en e2e.
- **Écritures sérialisées** dans la page voyage (`createSerialQueue`).
- **Toute suppression est confirmée**, faute d'annulation avant le lot 5.
- **Durée par défaut d'une randonnée** : 3 h, provisoire jusqu'au calcul GPX du lot 6.

## Bugs et pièges rencontrés

- **Zones de dépôt qui grandissaient pendant le glisser** : la liste se décalait sous le curseur, et en e2e le second dépôt tombait ailleurs (4 échecs sur 5). Les zones ont désormais une hauteur fixe ; le survol ne change que la couleur.
- **Deux écritures rapprochées** partaient avec la même version, et la seconde recevait un faux 409. Correction : file d'écritures, version lue à l'exécution.
- **E2E « dossier »** : après un dépôt, il faut attendre l'affichage avant le glisser suivant (la cible change de place).
- **`core` sans DOM** : `URL` n'est pas typé dans `core` (lib ES2022 seule). La validation des liens passe par une regex.
- **Petits écarts de TDD** :
  - `osm.ts` : test et code écrits dans le même lot, sans exécution intermédiaire en rouge ;
  - trois tests mal écrits, corrigés après leur premier échec : index de `positionAt`, sélecteurs de bouton trop larges.
